# Project instructions

- Product codename: Project Pulse. Keep branding configurable.
- Build mobile-first and maintain keyboard-accessible desktop behavior.
- Never claim news is verified without stored evidence and source links.
- Never expose individual votes or small demographic result slices.
- Implement features vertically: schema, policy, API, UI, tests, documentation.
- A feature is complete only after lint, typecheck, tests, and relevant build checks pass.
- Prefer a modular monolith until measured scale justifies extraction.
